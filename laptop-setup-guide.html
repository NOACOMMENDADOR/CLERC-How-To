Purpose

Configure a CLERC-owned Windows laptop consistently for a new or reassigned employee, including Windows setup, required applications, browser and cloud access, security checks, and workstation hardware.

Windows 11 Microsoft Intune Google Workspace LastPass Company Portal Airtable

Scope

This SOP covers the hands-on laptop setup completed after the device has been wiped and is at the Windows first-run setup screen. Detailed Intune configuration, group assignment, account creation, licensing, and other administrative provisioning may be covered by separate procedures.

Prerequisites

Device Ready Laptop has completed the offboarding/reset SOP and is at the Windows first-run setup screen
Accounts Created Employee Microsoft, Adobe, and Google accounts created with required licenses assigned
Intune Groups Employee is assigned to the correct device-management / Intune groups
Permissions Ready Shared calendars, Drive access, LastPass shared folders, Adobe, Asana, and role-specific permissions provisioned
💡
Have these available at the workstation: Office Wi-Fi credentials, charger, external keyboard/mouse, monitors, HDMI splitter/dock, and any role-specific peripherals.

Section 1 Windows First-Run Setup

STEP 1

Complete Region and Keyboard Screens

  1. Set Region to United States.
  2. Set Keyboard / input layout to US.
  3. Skip the second keyboard layout screen.
  4. Connect to the CLERC office Wi-Fi network.
STEP 2

Allow Windows to Check for Updates

Let the automatic update check complete before continuing. If Windows requires a restart during setup, allow it to restart and continue from where it left off.

STEP 3

Set Up the Device for Work

  1. At the "How would you like to set up this device?" screen, select Set up for work or school.
  2. Sign in with the employee's Microsoft account.
STEP 4

Complete Privacy and Manufacturer Preferences

  1. Privacy settings: leave at the CLERC-approved/default settings unless policy has changed.
  2. Skip the first Preferences screen, if shown.
  3. On the second Preferences screen, select the "I have read" checkbox and clear/unselect the McAfee checkbox, if shown.
⚠
Do not accept the McAfee installation. CLERC uses Windows Defender as its endpoint protection.
STEP 5

Complete Windows Hello and MFA Setup

  1. Skip fingerprint enrollment during initial staging unless the employee is present.
  2. At the Windows Hello screen, continue as prompted.
  3. Install Microsoft Authenticator on the employee's phone and complete MFA enrollment.
  4. Create a unique 6-digit Windows Hello PIN for the employee.
  5. Record the PIN in the relevant Airtable record and in a LastPass note within the employee's shared folder so it can be provided to the employee at handoff.
🔑
The PIN must be recorded in two places: the Airtable employee record and the employee's LastPass shared folder. Both are needed so the PIN can be provided at handoff.

Section 2 Windows & Taskbar Configuration

STEP 6

Finish Windows Updates

After reaching the desktop, open Settings > Windows Update. Check for updates and install everything until the device reports it is current. Restart as needed.

💡
This may take multiple rounds of check-install-restart. Keep going until Windows Update shows "You're up to date" with no pending items.
STEP 7

Configure Taskbar Settings

Go to Settings > Personalization > Taskbar.

  • Turn off Task View.
  • Turn off Widgets.
  • Turn off Resume (if present).
  • Under Taskbar behaviors, set Taskbar alignment to Left.
STEP 8

Set Taskbar Pins

Adjust the taskbar pins to match the CLERC standard layout:

Pin these apps:
+ Company Portal + Google Chrome + Microsoft Word + Microsoft Excel + Adobe Acrobat + Asana + Zoom
Unpin these:
Microsoft Edge Microsoft Store Dell shortcut Microsoft 365 Copilot
📌
If Adobe Acrobat is not yet installed, it will be installed in Step 15. Pin it to the taskbar after that step.
STEP 9

Clean Up the Desktop

Remove the Microsoft Edge desktop shortcut. Leave Windows system components installed unless this SOP specifically calls for uninstalling them.

Section 3 Chrome, Google & LastPass

STEP 10

Set Up Google Chrome

  1. Open Chrome and sign in to the employee's CLERC Google profile.
  2. Set Chrome as the default browser.
  3. Sign in to LastPass and install/enable the LastPass browser extension.
  4. Open Chrome menu > Bookmarks and lists > Show bookmarks bar.
STEP 11

Create Standard Bookmarks

Add the following bookmarks to the bookmarks bar:

  • Gmail
  • Google Calendar (confirm the employee has access to all calendars required for their role)
  • QuickBooks Time / TSheets: tsheets.intuit.com
  • Google Drive: drive.google.com
  • Other role-specific bookmarks as needed.
STEP 12

Configure Google Drive for Desktop

Open Google Drive for desktop (should already be installed through device management) and sign in with the employee's CLERC Google account. Confirm the application starts normally and the employee can access the expected Drive locations.

Section 4 Application Setup

STEP 13

Set Up Asana

  1. Browse to app.asana.com.
  2. Create or activate the employee's account using their CLERC Google sign-in, if it has not already been provisioned.
  3. From Asana settings, download the desktop app.
  4. Install Asana and pin it to the taskbar.
STEP 14

Set Up Zoom

  1. Open Zoom.
  2. Create or activate the employee's CLERC Zoom account if it has not already been provisioned.
  3. Sign in and confirm the app opens correctly.
  4. Pin Zoom to the taskbar.
STEP 15

Set Up Adobe Acrobat

  1. Open Company Portal and install Acrobat Reader DC / Adobe Acrobat if it is not already installed.
  2. Sign in to the employee's CLERC Adobe account using the organization-approved credential process.
  3. If Adobe prompts for an available application update, install the update.
📌
If you skipped pinning Adobe Acrobat in Step 8, go back and pin it to the taskbar now.

Section 5 Remove Unneeded Applications

STEP 16

Uninstall Bloatware

Go to Settings > Apps > Installed apps. Uninstall the following when present and when not required for the employee's role:

✕ McAfee
✕ Dell Digital Delivery
✕ Microsoft Family
✕ Mail & Calendar
✕ Microsoft Teams
✕ Microsoft Outlook
✕ Xbox applications
✕ Microsoft OneNote
⚠
Role-specific exception: Do not remove an application that the employee's role actually requires. If CLERC later standardizes a different application list through Intune, the managed configuration should take precedence over this manual cleanup list.

Section 6 Security Verification

STEP 17

Verify Windows Security

  1. Search Windows for Virus & threat protection.
  2. Confirm required protection settings are turned on.
  3. Confirm security intelligence/definitions are up to date.
  4. Resolve any active Windows Security warnings before handoff.
STEP 18

Verify Company Portal / Managed Applications

Open Company Portal and confirm it loads correctly. Verify expected managed applications are present or available. Complete any required installs that have not arrived automatically.

Section 7 Workstation Hardware Setup

STEP 19

Connect Peripherals

Connect the external keyboard and mouse and verify both work correctly.

STEP 20

Connect and Arrange Monitors

  1. Connect monitors through the HDMI splitter, dock, or approved adapter.
  2. Open Settings > System > Display.
  3. Set the displays to Extend.
  4. Drag the display boxes into the physical left-to-right arrangement used at the workstation.
  5. Confirm the pointer moves naturally across all screens and the correct primary display is selected.

Final Airtable & Employee Handoff

Update Airtable Records

Update all relevant Airtable records before handoff. At minimum, confirm the employee and device/equipment records reflect:

  • Correct laptop assignment and asset tag or serial number
  • Setup status and setup date
  • Windows Hello PIN location/record according to CLERC's current tracking practice

Employee Handoff

Before the laptop is issued:

  1. Provide the employee with their Windows Hello PIN and confirm they can sign in.
  2. Confirm the employee can access email, calendar, and Google Drive.
  3. Confirm MFA is working on their phone.
  4. Provide the charger and assigned accessories.
  5. Update the relevant Airtable records to show the laptop assignment and handoff date.
