What This Guide Covers

The complete lifecycle of a Request for Proposals (RFP) at CLERC, from initial document preparation and internal review through contractor outreach, site visits, Q&A posting, and final award notification. The process is managed primarily through Asana, with files stored in Google Drive and communications sent through Bloomerang.

Team note: Many subtasks within the "Solicit Bids from Contractors" Asana task may be assigned to different people depending on ops team availability. Work is often split among team members. Pay attention to task assignments and communicate with the team to make sure work is distributed properly and that no one is duplicating effort.

Phase 0: RFP Folder Setup Setup

Before beginning the RFP process, the project folder must exist with the correct structure. Laura typically creates this well before the project goes out to bid, but if it hasn't been set up yet, create it yourself.

Location: Operations > Agreements & Contracts > RFP-Request for Proposals

1

Copy the template folder

Find the folder named ZZZ NewProjectFolderTemplate MAKE A COPY. This folder contains all required subfolders (PDFs, Emails & Communications, Proposals for Evaluation, Maps) and all template files already placed in the correct locations.

Make a copy of the entire folder (right-click > Make a copy in Google Drive).

2

Rename the folder

Rename the copy to: RFP-#### [Project Name]

RFP numbers are assigned in ascending numerical order. Choose the next number after the most recently assigned one so the folder sorts correctly within the parent directory.

3

Rename the Links file

Open the copied folder and rename the RFP Links file in Emails & Communications to: RFP-#### [Project Name] - Links

📌

The SOW and Map are not included in the template folder. These are created by the stewardship team and saved in the project folder under Fire & Forestry > GRANTS > [grant funding the project] > PROJECTS > [Project Name]. They get copied into the RFP folder during Phase 1.

Phase 1: Verify Prerequisites Setup

Before starting the RFP process, two items must already be complete:

1

Scope of Work (SOW)

  • Check the Asana task to confirm the SOW has been completed by Cindy.
  • Cindy typically saves SOWs in: Fire & Forestry > GRANTS > [grant funding the project] > PROJECTS > [Project Name]
  • If the SOW is not already in the RFP project folder, copy it there.
  • Rename (if needed) to match naming convention: RFP-#### - Exhibit A - SOW [Project Name] - [Year]
2

Project Map

  • The project map is typically created by Dylan or another stewardship team member. Check the Asana project for the map task to see who it's assigned to and whether it's been marked complete. Contact the assignee if you need a status update.
  • The map is often saved in the same grants folder structure as the SOW: Fire & Forestry > GRANTS > [grant] > PROJECTS > [Project Name]
  • Copy it to the RFP project folder if not already there.
  • Rename to: RFP-#### - Exhibit B - [Project Name] Map - [Year]

Phase 2: Create the RFP Document Drafting

1

Verify templates are in place

If you created the project folder from the template in Phase 0, all template files should already be present. Confirm these are in the folder before proceeding:

  • The correct RFP template (choose based on treatment type: Fuel Break vs. Roadside Clearing)
  • CLERC Contractor Proposal Form Template (PRINT version, with fill-in lines for handwriting)
  • DIGITAL Contractor Proposal Form Template (without fill-in lines, for the online fillable version)
  • Bid Walk Agenda
  • Bid Walk Sign-In Sheet
  • RFP Links file (in the Emails & Communications subfolder, renamed to RFP-#### [Project Name] - Links)

About the Links file: This is a simple text file that serves as the central reference for all links generated during the RFP process. You'll add links to it throughout Phases 6-13. It contains these sections:

  • RFP: (Squarespace-hosted PDF link)
  • SOW Exhibit A: (Squarespace-hosted PDF link)
  • Map Exhibit B: (Squarespace-hosted PDF link)
  • Proposal Form: (Squarespace-hosted PRINT PDF link)
  • Digital Proposal Form: (Adobe web form link)
  • RSVP Link: (Easy-RSVP invite link)
  • Q&A Section Link: (Squarespace anchor link)
2

Fill in the RFP document

  1. Open the RFP template file in the RFP project folder.
  2. Scroll through the document and fill in all highlighted areas. These include:
    • Project name (appears in multiple locations)
    • RFP number (appears in multiple locations)
    • Project timeline dates
    • Job walk date, time, and location
  3. Before finalizing the job walk date/time: Confirm that Cindy and at least one ops team member are available. Once confirmed, add the event to Google Calendar and invite the appropriate parties. At minimum, invite Cindy and Laura. Depending on staff availability, a project coordinator and an ops team member should always be included.
  4. Confirm the site walk meeting location with Cindy and fill it into the highlighted "Location" field.
  5. Update the document footer to reflect the current project.
  6. Save the file as: RFP-####-[Project Name]
  7. Delete the original template file from the RFP folder (you now have the filled-in version).

Phase 3: Fill In the Contractor Proposal Forms Drafting

Both the PRINT and DIGITAL versions of the Contractor Proposal Form are already in the project folder from the template. You need to update both with the current project information.

1

Fill in the PRINT version (with fill-in lines)

  1. Open the PRINT Contractor Proposal Form template in Word.
  2. Add the RFP number on the top line, along with the project name.
  3. After "Estimated Total Cost," add the acreage in parentheses, e.g., (45 acres), using the acreage from the Scope of Work.

Critical: The acreage MUST match between the proposal form, the map, and the SOW. Cross-check all three.

  1. Update the footer with the correct project information.
  2. Review the page layout. Make sure sections haven't split awkwardly across pages.
  3. Save the file as: RFP-####-[Project Name] - Contractor Proposal Form
2

Fill in the DIGITAL version (without fill-in lines)

  1. Open the DIGITAL Contractor Proposal Form template in Word.
  2. Fill in the same project information: RFP number, project name, acreage after "Estimated Total Cost," and footer.

Critical: Make sure all information matches exactly between the PRINT and DIGITAL versions and the SOW.

  1. Review the page layout.
  2. Save the file as: DIGITAL RFP-####-[Project Name] - Contractor Proposal Form

Phase 4: Internal Review Drafting

1

Submit for review

  1. Once the RFP, SOW, Map, and Contractor Proposal Form are all completed, go to the Asana project and use the "Draft RFP" task to signal that drafting is done.
  2. Assign the review subtasks (currently unassigned) to the relevant reviewers.
  3. Notify all reviewers where the files are located and ask them to review as soon as possible.
  4. Wait for all reviewers to complete their review and incorporate any requested edits. If reviewers provide conflicting feedback, escalate to Laura for a final decision.

Phase 5: Create PDF Versions Digital Prep

Once all reviews are complete and edits have been incorporated:

1

Save all documents as PDFs

  1. Open each of the following files in Word and save as a PDF (File > Save As Adobe PDF) into the PDF subfolder within the RFP project folder:
    • The RFP document (keeps its original name)
    • The SOW / Exhibit A (keeps its original name)
    • The PRINT Contractor Proposal Form — save the PDF with the PRINT prefix, e.g., PRINT RFP-####-[Project Name] - Contractor Proposal Form.pdf
    • The DIGITAL Contractor Proposal Form — save the PDF with the DIGITAL prefix, e.g., DIGITAL RFP-####-[Project Name] - Contractor Proposal Form.pdf
  2. The map should already exist as a PDF. Copy it into the PDF folder alongside the other files.

Result: The PDF folder now contains:

  • RFP document (PDF)
  • SOW / Exhibit A (PDF)
  • Project Map / Exhibit B (PDF)
  • PRINT Contractor Proposal Form (PDF), for printing and handwriting
  • DIGITAL Contractor Proposal Form (PDF), for the online fillable version

Phase 6: Digitize the Contractor Proposal Form Digital Prep

This step turns the DIGITAL PDF into an online fillable form that contractors can complete and submit electronically.

Prerequisites: Have the PDF folder open and accessible.

1

Create the Adobe Web Form

  1. Navigate to Adobe Acrobat and sign in using the documents@theclerc.org account.
  2. Under the E-Sign dropdown menu, select Create Web Form.
  3. Upload the DIGITAL PDF version of the Contractor Proposal Form (drag and drop or file select).
  4. Leave the form name as-is (it defaults to the file name).
  5. Under "Select the required participant action to complete the form":
    • For participant #1, click the "Sign" dropdown and change it to "Fill Form" (this requires the contractor to fill out the form, not just sign it).
  6. Under "Add optional participants":
    • Click the plus sign, use the dropdown to select "CC / Copied", and enter documents@theclerc.org. This ensures CLERC receives a copy when a contractor submits.
  7. Click the blue Next button in the top right.
2

Setting up form fields

  1. The form should now display the proposal form without the fill-in lines. You need to create text input boxes for each fillable area.
  2. In the top-left corner, click the clipboard icon with the blue number badge. This auto-populates fields on the current page.
  3. Review the auto-populated fields:
    • Delete any fields that landed on top of pre-filled areas (like the RFP number and project name that you already entered). Select them and press Delete, or right-click > Delete.
    • For remaining fields, make sure each one is aligned with the correct fill-in area. Resize as needed.
  4. For areas that had multiple lines (where you removed the underlines in Word), you may need to manually add a text box:
    • Drag "Text Input" from the right sidebar (under Data) into the appropriate area.
    • Resize the box to match the available space, left-aligned with other text on the page.
  5. For any multi-line text boxes: Right-click the box > Edit > check "Multi-line Data Entry" > expand the Appearance section > set font size to 12 > Save. This must be done for every box that allows more than one line of text.
  6. Repeat steps 2-5 for each page of the form (click the clipboard icon on each page to auto-populate, then review and adjust).
  7. When all pages are complete, click Next and continue.
3

Test the form

  1. The next screen displays a shareable link. Copy the first link.
  2. Test before sharing: Open the link in an incognito/private browser window and fill out a test submission. Verify that all fields accept input, multi-line boxes work correctly, and the form submits without errors. After testing, delete the test submission from the Adobe Acrobat dashboard.

Editing after creation: If you need to make changes to the form after it's been created, you can access your web forms under E-Sign > Web Forms in the Adobe Acrobat dashboard at acrobat.adobe.com.

4

Save the share link

  1. Paste the link into a comment on the Asana subtask: [Project Name] > Solicit Bids From Contractors > Digitize the Proposal Form. Mark that subtask as complete.
  2. Open the RFP Links file (Operations > Agreements & Contracts > RFP-Request for Proposals > [project folder] > Emails & Communications > [Links file]).
  3. Paste the Adobe form link under the "Digital Proposal Form" section of the links file.
  4. Save the links file.

Phase 7: Upload PDFs to Squarespace Digital Prep

This step generates hosted file links for all PDFs by uploading them through the Squarespace editor. You need backend access to Squarespace.

Why this works the way it does: Squarespace doesn't have a standalone file upload tool. The only way to upload a file and get a hosted link is through a block that accepts file attachments (like a Button block). So we temporarily add a button, use it to upload each file and copy the generated link, then delete the button. The files remain hosted on Squarespace even after the button is removed.

1

Upload files via Button block

  1. Navigate to the Squarespace Pages dashboard.
  2. In the left navigation, go to Website > Pages.
  3. In the left sidebar, click Pages, expand the Connect section, and select the Contractor Interest Form page.
  4. Click Edit and scroll down to the first section below the banner.
  5. Add a Button block (placement doesn't matter; it will be deleted).
  6. Double-click the button to open the edit dialog. Click Attach Link.
  7. Use the dropdown (currently says "URL") and change it to File.
  8. Click Upload and navigate to the PDF folder for your project. Select the SOW file.
  9. Click out of the button editor, then click back into it. Click Copy to copy the generated file link.
  10. Paste that link into the SOW section of the RFP Links file.
  11. Click Remove Link (in the button editor).
  12. Repeat steps 6-11 for:
    • The RFP document
    • The Project Map
    • The PRINT Contractor Proposal Form
    • Save each link to the appropriate section of the Links file.
  13. Save the Links file when all four links have been added.
  14. Delete the button block from the page and exit the editor.
  15. Go to the Asana subtask: [Project Name] > Solicit Bids From Contractors > Upload all documents to the website in PDF format. Mark it complete.

  8. Copy the "Super Secret Admin" link and paste it into the Asana subtask: [Project Name] > Solicit Bids From Contractors > Create RSVP Link. Mark that task complete.
  9. Copy the invite link and paste it into the RFP Links file under the RSVP Link section. Save the file.

Phase 12: Attend the Job Walk and Draft the Q&A Document Site Visit

1

Before the job walk

  1. Check how many contractors have RSVPd.
  2. Print and update (fill in all highlighted fields) the following from the templates folder:
    • Job Walk Sign-In Sheet
    • Bid Walk Agenda
  3. Print packets containing the RFP, SOW, and Map stapled together. Print enough for:
    • All confirmed contractors
    • All attending staff
    • 2-3 extras for unannounced attendees
  4. Bring all printed materials and pens.
2

During the job walk

  1. Your primary job is to record all questions asked and answers given. Questions mostly come from contractors, but the stewardship team may also provide important project information unprompted.
  2. At the start of the walk, the stewardship team will clarify the prescription and give a safety briefing. Take notes on this information for the Q&A document (there are dedicated sections for it).
  3. After the stewardship overview, give a brief summary of project deadlines. This gives contractors a chance to ask timeline-related questions.
3

After the job walk: drafting the Q&A

  1. Find the most recently completed Q&A file from a previous RFP project and copy it into your current RFP project folder. There is no blank Q&A template; completed Q&A files from past projects serve as the template. If you're unsure which project was most recent, check the RFP folders in Operations > Agreements & Contracts > RFP-Request for Proposals in descending order.
  2. Rename the file to: RFP-#### [Project Name] Q&A and update all headers/footers to the current project.
  3. Review the "Clarifying Prescription" and "Safety Briefing" sections. Much of this can often be reused between projects. Remove anything that doesn't apply and add your new notes.
  4. Delete all questions from the previous project.
  5. Add the questions and answers you recorded. Match the tone and language style of previous Q&A documents (review past ones to get a feel for it).
  6. Save the file in the main RFP project folder.
  7. In Asana, go to the subtask "Draft Q&A and have reviewed" under Solicit Bids From Contractors. Tag Laura with a comment that the Q&A is drafted and ready for review. Include a Google Drive link to the file.
  8. Laura (or another ops member) will create review subtasks assigned to Cindy, Tracy, Teresa, Will, or other relevant reviewers.
  9. Once all reviewers have approved and edits are incorporated, do a final review. Double-check that no last-minute questions have come in via email.
  10. Mark the subtask complete.

Phase 13: Post Q&A to Website and Send Q&A Email Site Visit

Prerequisites: The Q&A document must be fully reviewed and approved. You need Bloomerang access, Squarespace editing access, and a Claude account. Have the approved Q&A document, Links file, and RFP open.

Timing: The Q&A is posted and emailed on the day the questions deadline closes, after the deadline has passed.

Part 1: Generate the Q&A HTML using Claude

1

Generate the accordion HTML

  1. Open Claude in your browser.
