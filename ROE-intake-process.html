Purpose

Ensure all Right of Entry forms are accurately received, verified, processed, recorded, and communicated across all internal systems.

Bloomerang (CRM) Google Drive Google Sheets Adobe Acrobat documents@theclerc.org

Step 1: Identify the ROE Submission Type

✉
Physical (Mailed Hard Copy) Follow Path A below
💻
Digital (Email Approval) Skip to Path B below

Physical (Mailed) ROEs Path A

A1

Mail Intake & Sorting

  1. Open all incoming ROE mail.
  2. Separate ROEs into piles by grant (typically CWDG-1 or CWDG-2).
  3. Keep ROEs grouped by grant to maintain reporting accuracy and minimize context-switching.

How to determine grant: Recognize the project area or address, or search the property owner/address in Bloomerang and check the "Groups" field. If unsure, set the ROE aside and resolve before scanning.

Time tracking: Charge sorting time to Admin. Once working within a specific grant, switch time to that grant.

A2

Scanning Documents

  1. Scan all ROEs using the office scanner.
  2. Each ROE must be its own individual PDF (do not combine multiple ROEs into one file).
  3. Scan in the same order as your sorted piles.
  4. Save to: Google Drive → My Drive → From Brother Device

Quality check: Confirm all pages are legible and nothing is cut off or rotated incorrectly before moving on.

A3

Begin Processing (By Grant)

  1. Open the scanned folder.
  2. Select the first ROE from one grant pile.
  3. Switch time tracking to that grant.
A4

Identify Property Owner & Project

  1. Open the scanned ROE and locate the property owner name and property address.
  2. Search in Bloomerang by name first, then by address if not found.
  3. If the property owner has a profile, open it and confirm the project under Profile → Groups (e.g., "Bottle Rock Roadside 2026").

Profile not found? Property owners are not pre-added to Bloomerang when ROEs are sent out, so many will not have an existing profile. If no profile exists, you will create one in step A7. For now, use the Master Project Parcel List spreadsheet or the ROE form itself to identify which project and grant the property belongs to.

A5

Open Required Project Files

Open all three of the following in separate tabs:

  1. Project Google Drive folder (navigate to the ROE subfolder within it)
  2. Master Project Parcel List (Google Sheet for the relevant project)
  3. Bloomerang (the property owner's profile, or the Bloomerang home page if you need to create one)
A6

Accept & Complete ROE (Adobe Acrobat)

  1. Open the ROE in Adobe Acrobat.
  2. Use Fill & Sign to complete: Signature, Title, Date, Grant Code.
  3. Close the Fill & Sign tool.
  4. Save As → Choose a Different Folder → navigate to the correct project ROE folder in Google Drive.

File naming convention:

[Property Owner Name] – ROE – [Project Name] – [MM.DD.YY]
A7

Update or Create Bloomerang Profile

Search Bloomerang for the property owner by name, then by address. If a profile already exists, skip ahead to "Update the profile" below.

If no profile exists: Create a new one

Determine whether to create a Constituent (individual person) or an Organization profile based on the owner name on the ROE:

  • Individual name (e.g., "Karen Albertson," "John & Mary Smith") → Create a new Constituent
  • Business, LLC, trust, or organization name (e.g., "Clearlake Vista Resort LLC," "Smith Family Trust") → Create a new Organization

Enter all available information from the ROE: name, mailing address, phone, and email. Add the property owner to the correct project group under Profile → Groups.

Update the profile

Contact Information: Add any phone, email, or alternate mailing address provided on the ROE.

If different contact info already exists on the profile, add the new info as the primary entry. Do NOT delete existing data.

If owned by a business or trust

Click "Edit" on the Organization profile and add the primary contact person's name.

Landowner Information section:

  1. Set Current ROE to Yes.
  2. Select the appropriate Property Owner Type from the dropdown:
    • Business — The property owner is clearly a business or organization name (LLC, trust, company, resort, etc.).
    • Absentee — The property owner's mailing address is located outside of Lake County.
    • Private Property Owner — The property owner is an individual with a mailing address within Lake County.
  3. Save the profile.

Why this matters: The Property Owner Type lets CLERC separate property owners within project groups by category for targeted fundraising asks in the future.

A8

Add Bloomerang Note

  1. Click Add Note.
  2. Enter: ROE signed by [Property Owner Name]. Accepted and Returned by [Your Name]
  3. Click + → Web Link → paste the Google Drive file link to the accepted ROE.
  4. Save the note.
A9

Update Master Project Parcel List

Open the Master Project Parcel List spreadsheet in Google Sheets for the relevant project.

  1. Find the row for the property (search by APN or property owner name in the OWNER column).
  2. In the RECEIVED column (column C), change the value from FALSE to TRUE.
  3. Highlight the entire row with a light green fill color.
  4. In the NOTES column (column CG), enter 2026 ROE (or the appropriate year). Hyperlink this text to the ROE file in Google Drive.
  5. Fill in contact details in the designated columns: Contact_Name_Title (column CH), Contact_Phone_Number (column CI), and Contact_Emails (column CJ).

Tip: If the ROE covers multiple parcels (multiple APNs), update each corresponding row in the spreadsheet.

A10

Send Confirmation

If an email address was provided
  1. Open documents@theclerc.org → Compose.
  2. Open Templates → "Manual: Thank You - Right Of Entry Form Received"
  3. Replace [First Name] and remove "Manual:" from the subject line.
  4. Attach the accepted ROE.
  5. Send.
If no email address was provided
  1. Print the accepted ROE.
  2. Open Google Docs → Template Gallery → "ROE Physical Acceptance Letter"
  3. Personalize the letter and print.
  4. Prepare envelope: print mailing label, add postage.
  5. Mail the acceptance letter along with a copy of the ROE.
A11

File Physical Copy

  1. Mark the physical ROE as completed (highlight or mark it off your pile).
  2. File it in the physical filing cabinet.

Digital ROEs Path B

B1

Intake & Review

  1. Open documents@theclerc.org and locate the ROE approval email.
  2. Click "Review & Approve".
  3. Scroll to confirm the property owner name and property address.
B2

Identify Property & Open Project Files

Follow the same lookup process as the physical path:

  1. Search in Bloomerang by name, then address. Same as A4
  2. If a profile exists, confirm the project via Profile → Groups. If not, you will create one in step B4.
  3. Switch time tracking to the correct grant.
  4. Open the project Drive folder, Master Project Parcel List, and Bloomerang in separate tabs. Same as A5
B3

Accept & Save ROE

  1. Complete the digital approval.
  2. On the confirmation screen, click "Download a Copy".
  3. Rename the file using the standard naming convention:
[Property Owner Name] – ROE – [Project Name] – [MM.DD.YY]
  1. Upload the renamed file to the project's ROE folder in Google Drive.
B4

Update All Systems

Complete the same system updates as the physical path:

  • Update or create Bloomerang profile, set ROE status and Property Owner Type A7
  • Add Bloomerang note with Drive link A8
  • Update Master Project Parcel List A9
B5

Send Confirmation

  1. Open documents@theclerc.org.
  2. Use template: "Thank You - Right Of Entry Form Received"
  3. Replace [First Name] and send.

Final Completion Checklist

Confirm all items before closing any ROE.
