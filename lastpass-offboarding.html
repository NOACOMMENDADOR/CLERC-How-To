Purpose

Securely remove a departing employee from LastPass when they quit or are terminated. This process locks them out, recovers any passwords the team still needs, and deletes their account.

LastPass Admin Console LastPass Vault

Before You Start

You need:

Super Admin Login The shared admin email address and its master password
Shared Folder Access The departing employee's shared folder, where you will save their new master password and any passwords worth keeping

⚠ Why the order matters

LastPass is zero-knowledge, which means no one can read a vault without its master password, not even an admin. If you delete the account before rescuing anything saved only in the employee's personal vault, that data is gone for good. The plan is to lock the account down first, set a master password you control, pull anything the team still needs into a shared folder, and only then delete.

Step 1 Disable the Account

1

Block the Employee's Login

  1. Go to admin.lastpass.com and log in with the shared admin email and master password.
  2. Select Users in the navigation.
  3. Find the employee by name or email and open their entry.
  4. Choose Disable (also shown as Deactivate). This blocks their login right away but keeps the account and vault intact.
💡
Disabling does not always kick out a browser extension that is still open on their device. The next step handles that.

Step 2 Destroy All Sessions

2

Force Logout on Every Device

  1. In the same user's menu, choose Destroy all sessions.
  2. This logs the employee out of every device immediately.
✅
Between Step 1 and Step 2, the employee is now fully locked out.

Step 3 Reset the Master Password

3

Set a Password You Control

  1. In the user's menu, choose the option to change the master password (the Super Admin option that sets the password immediately).
  2. Enter a new master password.
  3. Save that new master password into the employee's shared folder so any admin can find it later.
⚠
Watch for the two similar options. The plain "Reset master password" only prompts the user to change it the next time they log in, which will not happen since they are gone. You want the change master password option, which sets it right away. This requires Super Admin permission, which your shared account already has.

Step 4 Reactivate the Account

4

Re-enable So You Can Log In

  1. In the user's menu, change the account status back to Active.
💡
You need the account active again because you cannot log into a disabled account, and the next step requires logging in as the employee.

Step 5 Preserve Passwords the Team Needs

5

Log In and Rescue Vault Contents

  1. Log out of your admin account, or open a separate browser or incognito window so you do not disturb your admin session.
  2. Go to lastpass.com and log in with the employee's email and the new master password you set in Step 3.
  3. Review their vault. Move or copy any logins the team still needs into the employee's shared folder (or whichever shared folder makes sense).
⚠
Last chance. Anything left only in their personal vault will be lost once the account is deleted. Make sure everything worth keeping lands in a shared folder before you move on.

Step 6 Delete the Account

6

Permanently Remove the Account

  1. Log back into admin.lastpass.com as super admin.
  2. Select Users, open the employee's entry, and choose Delete User to remove the account entirely.
  3. Confirm when prompted.
⚠
Delete User vs. Remove User from Company. Delete User removes the account completely. Remove User from Company takes them out of your organization but can leave a personal account behind. For a full offboarding, use Delete User.

Step 7 Clean Up

7

Reassign Ownership and Tidy Records

  1. If the employee owned any shared folders, reassign ownership to a current admin before or right after deletion so nothing gets orphaned.
  2. Update the shared folder record if needed, since the old master password no longer applies once the account is gone.
